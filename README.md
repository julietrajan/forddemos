# Ford Copilot Delivery Kit - Fictional Training Assets

Classification: Public. This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## Purpose
This local package contains prompts, sample files, fictional emails, a meeting transcript document, a branded PowerPoint starter deck, and an Excel dataset for three one-hour Microsoft 365 Copilot sessions.

## Fictional company and scenario
The demo company is **Northstar Mobility**, a fictional Microsoft Fake Company preparing a connected-vehicle component launch. The content is public-safe, synthetic, and intended only for Microsoft 365 Copilot training.
