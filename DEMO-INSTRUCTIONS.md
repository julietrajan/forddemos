# Demo Instructions - Ford Copilot Delivery Kit

Classification: Public. This demo uses a fictional Microsoft Fake Company created for demonstration purposes. Any resemblance to real organizations, people, products, services, or data is coincidental. Do not use customer confidential information in this repository.

## How to use these materials
Run each session as a one-hour, demo-first workshop. The trainer should open the relevant sample files, copy prompts from this guide, and adapt follow-up prompts live based on Copilot output.

## Required sensitivity language
"Today we are using fictional, Public sample content. In production, apply your organization's sensitivity labels, respect DLP policies, and avoid entering regulated, customer-confidential, personal, or unreleased business information into prompts unless your tenant policies and the data label permit it. Copilot follows Microsoft 365 permissions and labels, but users are still responsible for choosing appropriate source content and outputs."

## Session 1: Copilot in Outlook & Teams

**Duration:** 60 minutes

**Objective:** Show how Copilot helps a busy program team summarize messages, draft responses, find tasks, and turn meeting content into next steps.

**Artifacts:** Sample Outlook .eml files, fictional Teams transcript Word document, prompt guide.

### Timing
| Time | Activity |
| --- | --- |
| 0-5 min | Context, fictional-data reminder, sensitivity language |
| 5-15 min | Instructor demo |
| 15-35 min | Guided prompt sequence |
| 35-50 min | Participant scenario challenge |
| 50-60 min | Debrief and best-practice prompts |

### Prompt boxes
#### Prompt box 1
```
Summarize the latest messages in this thread. Highlight decisions, risks, owners, and open questions.
```

#### Prompt box 2
```
Draft a concise reply confirming the action items I own. Use a professional tone and do not overcommit on dates.
```

#### Prompt box 3
```
Find project tasks mentioned across recent email and Teams messages. Return a table with task, owner, due date, and source.
```

#### Prompt box 4
```
Rewrite this note so it is clearer for an operations audience and add a short subject line.
```

#### Prompt box 5
```
Coach this reply for clarity, empathy, and executive tone. Suggest two stronger versions.
```

#### Prompt box 6
```
Summarize the attached quality review into three bullets and translate the customer-facing paragraph into Spanish.
```

#### Prompt box 7
```
From this meeting recap, create follow-up tasks grouped by owner and urgency.
```

## Session 3: Copilot in Excel

**Duration:** 60 minutes

**Objective:** Use Copilot to analyze a multi-sheet operational dataset, create charts, forecast trends, and identify data quality issues.

**Artifacts:** Excel workbook with operations, defects, forecast, lookup, and dashboard sheets.

### Timing
| Time | Activity |
| --- | --- |
| 0-5 min | Context, fictional-data reminder, sensitivity language |
| 5-15 min | Instructor demo |
| 15-35 min | Guided prompt sequence |
| 35-50 min | Participant scenario challenge |
| 50-60 min | Debrief and best-practice prompts |

### Prompt boxes
#### Prompt box 1
```
Analyze this workbook and tell me the three biggest operational issues by plant and product line.
```

#### Prompt box 2
```
Create a chart showing weekly defect rate by plant and highlight any worsening trend.
```

#### Prompt box 3
```
Build a management dashboard with throughput, defect rate, on-time percentage, and top risk drivers.
```

#### Prompt box 4
```
Forecast the next four weeks of throughput by plant and explain assumptions.
```

#### Prompt box 5
```
Find duplicates, missing values, and inconsistent product names in the Operations Data sheet.
```

#### Prompt box 6
```
Apply conditional formatting to flag defect rates above 3.5% and on-time delivery below 92%.
```

#### Prompt box 7
```
Extract shift type, product family, and week number into new columns and create a new worksheet with only high-risk records.
```

#### Prompt box 8
```
Analyze information across the Operations Data and Parts Risk sheets to recommend where to focus tomorrow's standup.
```
