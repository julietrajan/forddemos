## Copy/paste prompts

```
Using the Excel workbook Ford_Copilot_Excel_Demo_Data.xlsx, update this Word report with the latest plant quality summary, product family quality summary, and highest-defect records. Keep the same headings and table format.
```

```
From the Operations Data sheet, extract the top eight records by defect rate and insert them into the Highest-defect records table in this document.
```

```
Create an executive summary for this Word document using the Dashboard, Operations Data, and Parts Risk sheets. Include defect rate, on-time percentage, highest-risk plant, highest-risk product family, and recommended actions.
```

```
Compare the Excel data with this Word narrative. Identify any numbers or recommendations that appear outdated or inconsistent, then propose corrected wording.
```

```
Turn the quality review into a customer-safe update. Remove internal details, keep it under 120 words, and do not include confidential or unsupported claims.
```
